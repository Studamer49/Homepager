# Homepager

A simple, friendly homepage that anyone can use — kids, grandparents, everyone.

## How to use

1. Open `vivu_homepage_redesigned.html` in your web browser.
2. Tap the **⚙️ Settings** button (bottom right).
3. Tap **Categories → + Add category** to make a group of links.
4. Tap **+ Add link** inside a category, type a name and website address.
5. Close Settings. Your links show up on the page. Tap them to visit.

You can change colors, text, fonts, and what's shown — all in Settings. Nothing is saved to a server; your choices stay on your computer. Use **Save settings to file** to keep a copy, and **Load settings from file** to bring it back.

## What's included

- `vivu_homepage_redesigned.html` — the homepage (one file, works right away)
- `random.html` — a fun random-number page
